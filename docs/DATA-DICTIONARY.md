# 双写定义

event_id唯一，tenant_id与doc_id共同构成文档业务键，均按文本保留。受理两种表头：含tenant_id的11列新契约，以及缺tenant_id的10列旧契约；旧契约行按缺归属处理，tenant_id置空后送字段契约裁决。side为source或index；版本正整数按Decimal比较并作为文本序列化。upsert要求JSON对象，delete忽略payload并产生墓碑。相同租户相同文档同端同版本不同内容全部隔离，存在未裁决冲突的主体不回落旧版本；同内容合并来源；较高版本覆盖低版本，迟到旧写不得覆盖墓碑。同一文档号在不同租户重复出现时各自独立裁决，不互相冲突也不合并。

租户归属不许猜配：tenant_id为空或命中哨兵集合的行以TENANT_MISSING隔离；运行参数tenant_scope声明本次切换范围（非空字符串列表，空或缺省表示按输入推导），范围外租户以TENANT_OUT_OF_SCOPE隔离。缺归属与范围外内容一律不进入正式可见性结论。一篇文档形成唯一可见性结论的条件：归属已确认且在范围内、版本冲突已裁决、其(租户,文档)对在结论中至多出现一次；归档阶段对重复(租户,文档)键拒绝封存。tenant_scope在运行前规范化（去空白、去重、排序），同一逻辑范围的重跑产生同一批次。

双端最终版本、操作、文档分别核验。目标缺失、删除未确认、索引领先、陈旧索引、内容差异分开展示。source_time与visible_time带偏移；可见延迟按实际秒数。默认阈值120秒，等于阈值通过。已可见但超过阈值为延迟，尚无目标且等待时间超过阈值为缺失，等待中不冒充延迟。

对账expected=每文档应通过的1，reported=门禁通过1或未通过0，逐条保存visibility_state和gate原因，允许按文档复核。可见性与归档指标携带tenant_scope（结论覆盖的租户集合），页面与证据CSV读取同一存储批次；证据CSV含tenant_id列与tenant_scope行（declared_scope为声明范围、concluded_scope为实际结论范围）。

业务ID和超大整数按文本保形；Decimal参与数量金额计算，对外序列化为字符串。哨兵集合定义在app/values.py，缺失值不能当零。所有时间带UTC偏移，先转UTC比较，业务日按指定地区划分。区间统一[start,end)。重复业务键保留第一条、完全相同行计重复；值冲突行隔离且保留原值。空文件、全空白、仅表头分开拒绝。

运行清单包括输入sha256、规则版本、参数、生成时刻与耗时。源行编号以CSV解析器的物理结束行号表示，引号内换行不增加记录数。输入超过4MB返回413，非法表头和类型返回422，失效版本复核返回409。
